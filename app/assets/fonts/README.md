# Terminal font

JetBrains Mono 2.304, from https://github.com/JetBrains/JetBrainsMono/tree/v2.304.
Distributed under the SIL Open Font License in `OFL-JetBrainsMono.txt`.

Bundling the regular and bold fonts gives xterm consistent monospace metrics in
Flutter's web renderer, including Edge, without relying on local system fonts.
